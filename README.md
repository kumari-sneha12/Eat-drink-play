# Eat Drink Play — Sidcup Family Golf

A single-page marketing website for **Sidcup Family Golf**, a multipurpose golf facility located in Sidcup, South East London.

## About the Project

This is a static front-end website built with HTML, CSS, and JavaScript. It showcases the facilities and services offered at Sidcup Family Golf, including:

- **TopTracer Range** — 46-bay, multi-tier, floodlit driving range powered by Toptracer technology
- **Adventure Golf** — Two outdoor 18-hole dinosaur-themed crazy golf courses
- **Golf Lessons** — Professional coaching for all skill levels
- **Coffee Shop** — On-site café with food and drink options (vegan and gluten-free available)
- **Leagues** — Organised competitive golf leagues

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and content |
| CSS3 | Styling, animations, and responsive layout |
| JavaScript (ES6) | DOM manipulation and interactivity |
| [GSAP 3.12.5](https://gsap.com/) | Smooth scroll and entrance animations |
| [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) | Scroll-driven animation triggers |

## Features

- Full-screen hero background video
- Custom animated cursor
- Horizontally scrolling marquee text
- Interactive 3D hover cards
- Scroll-triggered section animations
- Responsive mobile layout (breakpoint at 390px)
- Newsletter sign-up call-to-action
- Food & Drink section with imagery
- Testimonial quote section
- Gallery with hover effects

## Getting Started

No build step is required. Simply open `index.html` in a modern web browser, or serve the directory with any static file server:

```bash
# Python
python -m http.server 8000

# Node.js (npx)
npx http-server .
```

Then visit `http://localhost:8000` in your browser.
